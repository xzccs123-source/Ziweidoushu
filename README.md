# ziwei-core

紫微斗数命盘分析 Skill。综合三合派、飞星派、钦天四化等流派技法，通过问答交互对命盘进行针对性分析。强调推导驱动而非模板填空，叠宫+自化优先于飞化的时间定位方法。

兼容 Claude Code、Cline、Cursor 及任意支持 system prompt 的 LLM 平台。

## 功能

- 解析文墨天机等排盘软件导出的文字命盘
- 数据确认后先做大局定位（来因宫、生年四化、格局判断），然后等待用户提问
- 根据用户具体问题按领域深入分析：婚姻感情、事业财运、学业、健康、人际关系、大限/流年精批
- 事件时间定位采用三层叠合扫描（流年→大限→本命），叠宫+自化优先

## 使用方式

1. 从文墨天机或其他紫微斗数排盘软件复制文字命盘
2. 在对话中粘贴命盘，skill 自动触发
3. 确认数据解析无误后，系统输出大局定位
4. 根据具体需求提问，逐领域深入分析

**触发关键词**：紫微斗数、命盘、排盘、看盘、分析命盘、紫微、ziwei

## 分析方法论

综合运用以下流派技法：

- **三合派**：星曜组合、格局识别、三方四正
- **飞星派**：宫干四化飞宫、宫位能量交易
- **钦天四化**：生年四化与自化的互动（禄权科忌的能量形态理论）
- **河洛紫微**：河图配应、生态空间、体用定位

时间定位采用三层叠合扫描法（流年→大限→本命），核心理念：**叠宫+自化 > 叠宫（无自化） > 飞化信号**。先穷尽叠宫扫描，再拿飞化做辅助区分。

## 注意事项

- 本 skill 仅解析命盘文字，不提供排盘计算引擎
- 分析结果仅供研究或娱乐目的使用
- 支持文墨天机 App 导出的标准格式

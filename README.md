# ziwei-core

紫微斗数命盘分析 Claude Code Skill。综合三合派、飞星派、钦天四化等流派技法，对命盘进行系统性的全局分析，涵盖健康、学业、事业、财运、人际关系、婚姻感情等方面。

## 功能

- 解析文墨天机等排盘软件导出的文字命盘
- 自动生成命盘总报告（大局定位 + 十二宫简述 + 飞星路径 + 大限概览 + 总结）
- 按需生成专题报告：感情婚姻、事业财运、学业、健康、人际关系、大限精批、流年精批

## 安装

将 `SKILL.md` 复制到 Claude Code 的 skills 目录：

```
cp SKILL.md ~/.claude/skills/ziwei-core/SKILL.md
```

或使用 Claude Code 的 skill 安装功能。

## 使用方式

1. 从文墨天机或其他紫微斗数排盘软件复制文字命盘
2. 在 Claude Code 中粘贴命盘，skill 自动触发
3. 确认数据解析无误后，自动生成总报告
4. 根据具体需求追问，生成专题报告

**触发关键词**：紫微斗数、命盘、排盘、看盘、分析命盘、紫微、ziwei

## 分析方法论

综合运用以下流派技法：

- **三合派**：星曜组合、格局识别、三方四正
- **飞星派**：宫干四化飞宫、宫位能量交易
- **钦天四化**：生年四化与自化的互动（禄权科忌的能量形态理论）
- **河洛紫微**：河图配应、生态空间、体用定位

## 报告类型

| 报告 | 触发方式 | 内容 |
|------|----------|------|
| 总报告 | 每次分析自动生成 | 大局定位、十二宫简述、飞星路径发现、大限概览、总结 |
| 感情婚姻专题 | 用户追问 | 配偶画像、恋爱路径、婚期推定、婚姻质量评估、离婚风险评估 |
| 事业财运专题 | 用户追问 | 适合行业、财富来源、事业转折点、财务风险 |
| 学业专题 | 用户追问 | 学历上限、各阶段学业运势、关键考试分析、适合专业方向 |
| 大限精批 | 用户追问 | 指定大限内所有流年逐条分析 |
| 流年精批 | 用户追问 | 指定年份的十二宫叠宫分析、逐月关键时段 |

## 注意事项

- 本 skill 仅解析命盘文字，不提供排盘计算引擎
- 分析结果仅供研究或娱乐目的使用
- 支持文墨天机 App 导出的标准格式，其他排盘工具格式需测试兼容性
